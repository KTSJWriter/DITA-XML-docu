Introduction

Overview

Harness.io manages the full lifecycle of the CI/CD (Continuous Integration/Continuous Deployment) process. You can define and automate your build, test, and deployment pipelines using easy-to-configure YAML files, and the pipelines can also be version-controlled, making updates and changes simpler. Harness supports parallel execution of jobs, allowing you to run builds, tests, and deployments simultaneously.

Access and Roles

Go to MyAccess (go/myaccess) to request the necessary roles.

  • To use Harness: PP_SSO_Harness_io_platform_operator
  • To deploy to Production: PP_HRZ_SITEAD_Altus_Deployment (you must also have current SRE IPCF Training, previously known as "Think Twice"),

Requests go to your manager for approval and may take 40 minutes to sync. For information about other roles, see Harness.io Roles in MyAccess.

To log in to Harness, go here, click the "Single sign-on" button, and enter your PayPal email address.

Onboard Your Application

Console (Raptor/Kraken/Node.js)

Make sure you have requested the required roles and that you have completed SRE IPCF Training.

These instructions are for a new application. If your application was already onboarded to Harness, see Harness Pipeline Upgrade.
